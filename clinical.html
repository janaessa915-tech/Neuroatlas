Think like a neurologist.

01

Identify the findings

Start with the patient's neurological signs and symptoms.

02

Find the system

Decide which functional system is involved: motor, sensory, visual, language, or coordination.

03

Localize

Use the pattern of findings to narrow down the anatomical location.

04

Explain

Connect the clinical findings back to the structure or pathway responsible.
